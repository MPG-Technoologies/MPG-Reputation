## 3. Verified controls retained

- **Marketing page indexing remains closed:** `src/app/page.tsx`, `features`, `how-it-works`, `pricing`, `faq`, `trust`, `resources`, `reputation-check`, `reputation-report`, and `resources/[slug]` declare `robots: { index: false, follow: false }`. This restricts search indexing behavior; **it is not access control**.
- **Internal campaign workspace access remains gated:** `src/app/mr10-campaign-preview/page.tsx` checks `NODE_ENV !== "development"` and calls `notFound()`; it also declares `noindex,nofollow,nocache`. Owner verified HTTP 404 in a local production build. It is not an authenticated admin application; never expose an unsecured development server to untrusted networks.
- **No real visitor measurement through the current MR-10 taxonomy:** `src/components/marketing/funnel.ts` exports a deliberately **no-op** `track`. `measurement-model.ts` works with explicitly synthetic journey fixtures.
- **Assessment and conversion mock remain browser-only by code inspection:** `ReputationCheck.tsx` builds reports from current React state using `buildReport`; local contract tests check against storage and network submission. This inspection is not a browser network-security or hosted telemetry audit.
- **Publication readiness is fail-closed:** `publication-readiness.ts` has `canPublish: false`, `ownerReleaseAuthorized: false`, and a separately required owner decision; MR-10F composition and local checkboxes cannot authorize a publish action or persist approvals.
- **Trial/plan terminology is bounded:** current public-facing draft materials use **30 Free Review Requests** and explain that sending a request does not guarantee a published Google review. Pricing page describes proposed plan categories without approved numbers or checkout.
